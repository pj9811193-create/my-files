YouTube 3D Vision on Android

Make YouTube videos 3D on your phone, with red-cyan glasses or a headset viewer.

Read this first. Chrome on Android cannot run browser add-ons — that is a limit of Chrome itself. To use this on Android you need a browser that can run Chrome add-ons. Good options: Lemur Browser, Mises Browser or Kiwi Browser (free on the Play Store, except Kiwi which may need a direct download). Install one of those first.

Steps

  1. Install an add-on-capable browser from the list above, and open it once.
  2. Get the add-on file. Download youtube-3d-vision-full.crx (about 70 MB — the AI model is inside it, so nothing else is ever downloaded). There is also a small version, youtube-3d-vision-android.crx (8 MB), which fetches the model once on first use instead.
  3. Turn on add-on installs in that browser: open its menu → Extensions (or Add-ons) → enable Developer mode.
  4. Install from the file: choose Install from file / Load from file and pick the .crx you downloaded. If your browser only offers "Load unpacked", unzip youtube-3d-vision.zip first and pick the folder named youtube-3d-vision.
  5. Open YouTube, play any normal video, and tap the small 3D button in the player controls. 3D switches itself on after a few seconds — the panel appears as a sheet at the bottom of the screen.
  6. Put on your glasses. For cheap red-cyan glasses leave it on "3D glasses (red-cyan)". For a 3D TV or a phone VR headset, tap Side-by-side.

Confirm it worked — 30 seconds

  1. Open any normal YouTube video. A small 3D button appears in the player controls (bottom-right).
  2. Tap it: a panel slides up from the bottom of the screen.
  3. After a few seconds the panel's status line reads "AI depth active" — that means the AI is running and the 3D is on. Nothing else to tap.
  4. Put your glasses on. Done.
If the button never appears, the add-on isn't enabled in that browser yet — check its extensions page. If the status shows an error, that video is protected and cannot be read; try another video.

What was tested

  • Package signature verified with OpenSSL — the same check a browser performs before installing. Result: Verified OK (both the 70 MB and 8 MB packages).
  • The extension was extracted from the shipped package itself and driven on a phone-sized screen (412×915) with real touch input: 48 px 3D button, tapping opens the panel, tapping the switch starts 3D, dragging a slider works, AI depth runs, stereo output on screen — 10/10 checks.
  • The panel is a bottom sheet sized to the display, so it can never be clipped inside the small player, and every control is at least 40 px tall for a fingertip.
  • Every file on the download site was hash-checked against the build — 31/31 match, and the split archive reassembles byte-for-byte into the shipped file.
  • Desktop is unchanged: the full end-to-end suite still passes 6/6 with the bundled model.
The one step that could not be run here is the browser's own install dialog on Android (Lemur/Kiwi/Mises are Android-only apps, and no Android device or emulator is available in this environment). Everything up to that point is verified — and the 30-second list above is how you confirm it in one go.

If something doesn't work

  • No 3D button on the video? Some add-on browsers hide the player controls; tap the video once to show them. Also check the add-on is enabled in that browser's extensions page.
  • Slow or warm phone? The AI runs on the phone's CPU. Open the panel and set Picture quality to Low, which processes fewer pixels.
  • Protected videos (some paid or DRM-locked ones) cannot be read — the panel will say so and normal playback continues.
  • Your browser only accepts a folder? Unzip youtube-3d-vision.zip and load the youtube-3d-vision folder with "Load unpacked" — that is the same code.

Everything runs on your phone. No video frames, history or personal data are ever uploaded.
